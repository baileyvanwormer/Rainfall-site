# Rainfall website

Support and privacy pages for Rainfall: Focus & Study Timer, hosted on GitHub Pages.

## Before publishing

1. Replace `YOUR-EMAIL@example.com` in `support/index.html` and `privacy/index.html` (2 places each) with the address you want users to contact.
2. Read the comment at the top of `privacy/index.html` and make sure the policy matches what the app actually does.

## Publish on GitHub Pages

1. Create a new **public** repository on GitHub named `rainfall`.
2. Upload everything in this folder to the repo root (Add file → Upload files), then commit.
3. In the repo, go to **Settings → Pages**. Under "Build and deployment", set Source to **Deploy from a branch**, Branch to **main**, folder **/ (root)**, then Save.
4. After a minute or two the site is live at `https://<your-username>.github.io/rainfall/`.

## URLs for App Store Connect

- Support URL: `https://<your-username>.github.io/rainfall/support/`
- Marketing URL (optional): `https://<your-username>.github.io/rainfall/`
- Privacy Policy URL: `https://<your-username>.github.io/rainfall/privacy/`

Open each one on your phone before submitting to make sure it loads.

## After approval

Update the button in `index.html` to link to your App Store page.
